## Verification discipline applied

- Name grepped against the 1048-key dedupe index before any fetch — no wasted fetches on known venues.
- A price is recorded only when an official or first-party ordering page states it. Where only a sister location's prices exist (L859), the price field is **null**.
- Absence rows are added deliberately: "verified to have no lunch special" is a real, useful, non-hallucinated result and stops repeat screening.
- Out-of-region results are rejected with the offending address quoted, so the trap is auditable.
- Every row and every rejection carries at least one HTTPS source link with a non-empty label; `check_links.py` enforces this.
