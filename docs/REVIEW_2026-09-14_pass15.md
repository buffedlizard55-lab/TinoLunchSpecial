## Method used for every row
1. **Discovery:** city-by-city and cuisine-by-cuisine searches with reproducible query URLs (`yelp.com/search?find_desc=Lunch+Specials&find_loc=<city>`, Chamber of Commerce restaurant-week pages, local papers). No candidate entered a batch from memory.
2. **Resolution:** each candidate had to resolve to one street address, one phone number and a per-day hours block from a page that could be cited. Where sources disagreed the disagreement is stored (flags above) rather than averaged.
3. **Price rule:** a price is printed only when it appears on the business' own page (ordering site, official menu) or is explicitly quoted as a reviewer/news figure with the quote attached. Photo captions, aggregator hallucinations and "starting at" marketing text never become prices.
4. **Absence is a result:** "no published lunch special" and "closed Tuesday" are recorded as findings, so the gaps are visible.
5. **Nothing was backfilled:** the merge script only accepted rows whose `verification.sources` list was non-empty and whose street address did not already exist in the master list.
